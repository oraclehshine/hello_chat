# Hello Chat UI Style Prompts

这份提示词用于后续继续扩展 `front` 前端，目标不是做炫技海报，而是保持主流聊天软件的可用性和熟悉感。

## 总体风格

设计一个主流中文聊天 Web 应用。视觉应接近微信 PC、Telegram Web、飞书消息模块这类高频沟通产品：左侧清晰导航，中间列表和会话内容优先，右侧只在需要时展示资料或设置。主色使用稳定蓝色 #1677FF，背景使用浅灰蓝 #F3F6FB，卡片和会话面板以白色为主，边框清晰，阴影克制，圆角中等，不要过度玻璃拟态。

## 登录注册入口

登录、注册、找回密码必须和主功能工作台分离。认证页可以使用两栏布局：左侧是简洁品牌说明和聊天能力摘要，右侧是聚焦表单卡片。表单标题清楚、输入框规整、按钮只有一个主操作，底部提供切换登录/注册/重置密码的文本链接。不要把聊天主导航显示在认证页。

## 主工作台

登录后进入主工作台。左侧为固定导航栏，包含概览、好友、单聊、群聊、朋友圈、个人资料。导航使用白底、浅灰边框、蓝色激活态，避免暗色大侧栏。主内容区按照聊天产品的模块组织，减少装饰背景，把空间留给会话列表、消息内容和操作按钮。

## 单聊和群聊

聊天页采用主流 IM 三段式结构：左侧会话/群组列表，中间消息流，必要时右侧显示成员、公告或文件。消息气泡简洁，自己发送的消息靠右并使用浅绿色或浅蓝色，别人消息靠左白/浅灰。未读角标、时间、搜索、发送栏要清晰可扫，不要过多装饰。

## 组件规则

按钮、输入框、卡片保持统一：主按钮蓝色，次按钮白底灰边，危险操作浅红底。输入框 46px 左右高度，10px 圆角，蓝色 focus ring。头像使用圆形，未设置头像时显示两位首字母。列表项 hover 使用浅灰蓝，激活项使用浅蓝底和蓝色文字。

## 移动端

移动端隐藏认证页左侧品牌区；主工作台侧栏堆叠到顶部；聊天列表和聊天窗口上下排列；表单按钮尽量全宽；保留足够点击区域。移动端优先可用性，不追求复杂装饰。

## 反向提示词

不要使用紫色 SaaS 默认风格、重玻璃拟态、夸张渐变、暗黑管理后台、过大海报视觉、无意义悬浮卡片、复杂阴影、AI 生成感强的插画堆叠。不要让认证页和主功能区混在一起。
