# Hello Chat 高并发改造续做进展
日期：2026-06-09

## 本次完成的开发

### 群聊链路完成 Kafka 事件化

- `GroupPushServiceImpl` 已从同步群成员遍历改为 Kafka 事件发布
- 新增 `GroupPushEvent`、`GroupPushKafkaListener`、`LocalGroupPushDispatcher`
- 群消息发送、撤回、删除、群资料更新类事件都会先进入 Kafka，再由消费者异步扇出到 WebSocket 节点

相关代码：
- `backend/src/main/java/com/hellochat/backend/service/event/GroupPushEvent.java`
- `backend/src/main/java/com/hellochat/backend/service/GroupPushKafkaListener.java`
- `backend/src/main/java/com/hellochat/backend/service/LocalGroupPushDispatcher.java`
- `backend/src/main/java/com/hellochat/backend/service/impl/GroupPushServiceImpl.java`

### Redis 开始承接群聊热数据

- 新增 `GroupHotCacheService`
- 新增 `GroupSummaryCacheValue`
- 群列表读取时，未读数、`@提及` 未读数、公告未读状态优先读取 Redis，未命中再回源数据库并回填缓存
- 群消息发送后会更新发送者自己的群摘要缓存，并通过 Kafka 消费侧异步更新所有成员的摘要与未读计数
- `markGroupAsRead`、`markNoticeRead`、`updateNotice`、`createGroup`、`joinByInviteCode`、`addMembers` 已补上缓存同步

相关代码：
- `backend/src/main/java/com/hellochat/backend/cache/GroupHotCacheService.java`
- `backend/src/main/java/com/hellochat/backend/cache/GroupSummaryCacheValue.java`
- `backend/src/main/java/com/hellochat/backend/service/impl/GroupServiceImpl.java`
- `backend/src/main/java/com/hellochat/backend/repository/GroupMessageRepository.java`

### Kafka 反序列化与配置补齐

- `GroupMessageResponse`、`GroupResponse` 已补充 Jackson 反序列化构造器
- `HighConcurrencyProperties` 与 `application.yml` 已新增 `group-push-topic`

相关代码：
- `backend/src/main/java/com/hellochat/backend/dto/GroupMessageResponse.java`

### Kafka 幂等消费与重复推送防护

- 新增 `KafkaEventDedupService`
- 单聊推送事件、群聊推送事件、WebSocket 分发事件都补充了 `eventId`
- `ChatPushKafkaListener`、`GroupPushKafkaListener` 已在消费前增加 Redis 去重门闩
- `WebSocketDispatchDispatcher` 已在最终推送前增加去重判断，覆盖 Kafka 重投与本地 fallback 重入场景
- 新增配置项 `kafka-event-dedup-ttl-seconds`，用于控制消费去重窗口

## 当前效果

- 群消息主链路已经从“写库后同步推送”演进到“写库后投递 Kafka，再异步广播”
- Redis 不再只服务单聊和 WebSocket 路由，已经进入群聊未读、提及未读、公告未读和会话摘要热路径
- 群消息 DTO 和群信息 DTO 可以稳定参与 Kafka JSON 序列化与反序列化
- Kafka 重复投递与推送 fallback 导致的重复下发风险，已经进入 Redis 幂等控制范围
